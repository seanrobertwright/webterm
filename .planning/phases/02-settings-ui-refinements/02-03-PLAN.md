**Windows implementation (primary target since this is a Windows dev machine):**
```typescript
import { exec } from 'node:child_process';
import { promisify } from 'node:util';
const execAsync = promisify(exec);

// Windows: Use PowerShell FolderBrowserDialog
const psScript = `
Add-Type -AssemblyName System.Windows.Forms
$dialog = New-Object System.Windows.Forms.FolderBrowserDialog
$dialog.Description = 'Select default start directory'
$dialog.ShowNewFolderButton = $true
$result = $dialog.ShowDialog()
if ($result -eq [System.Windows.Forms.DialogResult]::OK) {
  Write-Output $dialog.SelectedPath
}
`;
const { stdout } = await execAsync(`powershell -NoProfile -Command "${psScript.replace(/\n/g, '; ')}"`, { timeout: 60000 });
const selectedPath = stdout.trim();
```

Handle three cases:
- User selected a path: return `{ path: selectedPath }`
- User cancelled dialog: return `{ path: null, cancelled: true }`
- Error occurred: return 500 with error message

Also validate the selected path exists using `fs.existsSync` and `fs.statSync` to confirm it's a directory.

Add cross-platform support:
- `os.platform() === 'darwin'`: `osascript -e 'choose folder'` (parse POSIX path from result)
- `os.platform() === 'linux'`: `zenity --file-selection --directory`
- Default to Windows PowerShell approach

Browse button click handler:
```typescript
const handleBrowse = async () => {
  try {
    const res = await fetch('/api/v1/system/pick-directory', { method: 'POST' });
    const data = await res.json();
    if (data.path) {
      setDefaultStartDir(data.path);
    }
    // If cancelled, do nothing
  } catch (err) {
    // Show brief error — use console.warn per project conventions
    console.warn('Failed to open folder picker:', err);
  }
};
```

The text input should also be directly editable (user can type/paste a path). On blur or Enter, save via `setDefaultStartDir`. If the field is cleared, it saves as `''` (OS default).

Style the input+button group as a flex row: input takes remaining space, browse button is fixed width on the right. Use theme classes: `bg-input border-border text-foreground focus:ring-ring` for the input, `bg-secondary text-foreground hover:bg-secondary/80` for the browse button.
