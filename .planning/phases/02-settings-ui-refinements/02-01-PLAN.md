Replace the placeholder SVG element (lines 92-97, the 4-rect grid icon) with an `<img>` tag:

```tsx

  alt="WebTerm"

/>
```

Use CSS `filter` for theme colorization. Since the logo is a raster PNG, use the `drop-shadow` approach for a themed glow (consistent with existing glow aesthetics). Do NOT import the SVG file directly or use SVGR — it would embed 4MB of base64 in the JS bundle.
